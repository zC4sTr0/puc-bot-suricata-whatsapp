# Código de Conduta

O PUC Bot da Suricata é um projeto independente para estudantes e
mantenedores. Queremos um espaço seguro para aprender, revisar código e
discutir automação acadêmica sem expor pessoas.

## Esperamos

- tratar colegas com respeito, inclusive em dúvidas básicas;
- explicar decisões técnicas e ouvir correções;
- usar exemplos fictícios em issues, pull requests e testes;
- respeitar limites de privacidade, acessibilidade e segurança;
- discordar de ideias sem atacar pessoas.

## Não aceitamos

- assédio, discriminação, ameaça ou exposição de dados pessoais;
- publicação de token, QR, sessão do WhatsApp, JID real, nota, frequência,
  captura identificável do Canvas ou log de produção;
- tentativa de acessar conta, curso, grupo ou infraestrutura sem autorização;
- uso do projeto para vigiar, constranger ou individualizar estudantes.

Problemas de segurança não devem ser publicados em issue. Siga
[`SECURITY.md`](SECURITY.md). Para problemas de convivência, abra contato
privado pelos mantenedores do repositório, descrevendo o fato sem anexar dados
sensíveis. A moderação pode remover conteúdo, limitar participação ou encerrar
contribuições que violem estas regras.
